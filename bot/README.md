# Бот тестирования кандидатов — ООО «ОП «РЖД-ОХРАНА»

Бот в MAX: кандидат переходит из формы на сайте, отвечает на анкету
(ФИО/телефон/разряд — если не пришли с сайта) и проходит тест. Результат
пишется в Excel и (если настроена почта) уходит на email.

Стек: Node.js, `@maxhub/max-bot-api` (официальный SDK, dev.max.ru),
`exceljs`, `nodemailer`.

## Что уже сделано
- `questions.js` — вопросы теста с баллами + вопрос о разряде + порог
  прохождения (`PASS_THRESHOLD_PERCENT`, сейчас 60% — поправь если нужно)
- `scenario.js` — полный путь: приветствие (краткое повторение инфо с
  сайта) → кнопка «Пройти тест» → анкета (ФИО/телефон/разряд, анкету
  пропускает, если ФИО+телефон уже пришли по ссылке с сайта) → тест →
  запись в Excel → рассылка на почту
- `results-store.js` — копит кандидатов построчно в `data/candidates.xlsx`
  (ФИО, телефон, разряд, баллы, %, прошёл/не прошёл)
- `notify-email.js` — отправляет обновлённый файл на `EMAIL_TO` после
  каждого завершённого теста (nodemailer). Без `EMAIL_TO` — просто
  пропускает отправку, не ошибка
- `bot.js` — команды `/start`, `/test`, `/cancel`; разбирает ссылку с
  сайта (ФИО+телефон в start-параметре)

## Чего не хватает, чтобы запустить
1. **Токен бота.** Открой диалог с Master Bot в MAX (max.ru/masterbot),
   создай бота, получи токен и юзернейм. Впиши токен в `.env`
   (`cp env.example .env`), а юзернейм пришли — подставлю в кнопки на
   сайте (сейчас там плейсхолдер `rzd_ohrana_test_bot`).
2. **Почта для рассылки.** `EMAIL_TO` + SMTP-доступ (`SMTP_HOST/PORT/USER/PASS`
   в `.env`) — ты сказал «укажем позже». Без них файл просто копится
   локально в `data/candidates.xlsx`, никуда не улетает.
3. **Проверено чтением исходников SDK** (`node_modules/@maxhub/max-bot-api/dist`,
   пакет уже установлен, `npm install` прогнан) — не догадки:
   - ссылка с сайта приходит боту как отдельное событие `bot_started` с
     полем `ctx.startPayload` (не текст после `/start`, как в Telegram)
   - `scenarios.start(definition, createData)` — второй аргумент обязан
     быть функцией `(ctx) => data`, а переданные данные ПОЛНОСТЬЮ заменяют
     `createData` сценария, не мержатся с ним — учтено в `bot.js`
   Единственное, что реально нельзя проверить без токена — что сама
   платформа MAX действительно шлёт `bot_started` с payload именно в
   таком виде на боевом сервере (а не только в типах SDK).
4. Вопрос №5 из черновика (тест на внимание с показом на 5 секунд) не
   реализован — нужен отдельный механизм, не обсуждали формат.
5. Правки к вопросам — синхронизировать `../test-questions-draft.md` и
   `questions.js` вручную.

## Запуск (после получения токена)
```bash
cd bot
npm install
cp env.example .env
# вписать токен (и, если готова, почту) в .env
npm start
```

## Файл с кандидатами
`data/candidates.xlsx` — не в git (см. `data/.gitignore`), создаётся
автоматически при первом завершённом тесте. Столбцы: Дата, ФИО, Телефон,
Разряд, Баллы, Из максимума, Процент, Прошёл тест.
