# Бот тестирования кандидатов — ООО «ОП «РЖД-ОХРАНА»

Бот в MAX для прохождения теста кандидатами на должность охранника.
Стек: Node.js, `@maxhub/max-bot-api` (официальный SDK, dev.max.ru).

## Что уже сделано
- `questions.js` — вопросы теста с баллами (из `../test-questions-draft.md`)
- `scenario.js` — пошаговый сценарий: вопрос → inline-кнопки с вариантами →
  следующий вопрос → подсчёт итогового балла
- `bot.js` — команды `/start`, `/test`, `/cancel`

## Чего не хватает, чтобы запустить
1. **Токен бота.** Открой диалог с Master Bot в MAX (max.ru/masterbot),
   создай бота, получи токен. Скопируй `env.example` в `.env`, впиши токен
   в `BOT_TOKEN=`.
2. **Куда слать результаты теста.** Сейчас результат (баллы, ответы) только
   пишется в консоль (`console.log`) и не доходит до тебя. Нужно решить:
   отправлять тебе сообщением в MAX (нужен твой chat_id), писать в файл/базу,
   или что-то ещё.
3. **Финальное решение по вопросам** — если будешь править
   `test-questions-draft.md`, изменения нужно продублировать в `questions.js`.
4. Вопрос №5 из черновика (тест на внимание с показом на 5 секунд) в коде
   не реализован — требует отдельного механизма (таймер/картинка), не
   обсуждали формат. Пропущен, вопросы пронумерованы без разрыва (q1-q4,
   q6-q10 по исходной нумерации черновика).

## Запуск (после получения токена)
```bash
cd bot
npm install
cp env.example .env
# вписать токен в .env
npm start
```
