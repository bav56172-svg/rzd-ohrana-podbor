# План бота в MAX для тестирования кандидатов

## Как устроена платформа (по dev.max.ru)
- Официальный портал разработчика: dev.max.ru/docs
- Токен бота выдаёт **Master Bot** — открываешь диалог с ним в MAX
  (max.ru/masterbot), следуешь шагам, получаешь API token. Это может
  сделать только Андрей — привязано к его аккаунту MAX, у меня доступа нет.
- Два пути реализации:
  1. **No-code конструктор сценариев** (dev.max.ru/docs/chatbots/bots-nocode/create)
     — línейные сценарии с кнопками собираются без кода. Подходит для
     простого линейного теста (вопрос → варианты → следующий вопрос).
  2. **SDK/код** — есть официальный TS-клиент
     (github.com/max-messenger/max-bot-api-client-ts), похож на Telegraf.
     Подходит, если нужна логика: подсчёт баллов, автоотсев, ветвление
     по ответам, запись результатов в базу/файл.
- Публикация в маркетплейс MAX (модерация 3-5 дней) — для внутреннего
  HR-теста не нужна, бот не обязан быть публичным.

## Рекомендация
Наш тест (10 вопросов, часть с проходным баллом, часть — сценарные с
оценкой «правильного» поведения) — лучше на **SDK**, не в конструкторе:
нужна автооценка и, возможно, экспорт результатов тебе. Конструктор не
даёт гибкой логики подсчёта.

Стек: Node.js + max-bot-api-client-ts — ложится на существующую
инфраструктуру (bacey уже на Node.js).

## Что нужно от Андрея, чтобы начать сборку бота
1. Открыть диалог с Master Bot в MAX (max.ru/masterbot), создать бота,
   получить API token — прислать токен (как секрет, не светить в чате
   открытым текстом, лучше положить в .env на сервере и сказать мне путь).
2. Финализировать вопросы в `test-questions-draft.md` (что правишь/добавляешь).
3. Решить: бот сам выставляет проходной балл и отсеивает, или просто
   собирает ответы, а решение принимаешь ты вручную.

Как только это есть — собираю бота: скелет проекта, коммиты по шагам,
как обычно.
