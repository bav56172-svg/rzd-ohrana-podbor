## Готово (бот, bot/)
1. [x] questions.js — ДВА теста (Тест 1 «Квалификация» 10 вопросов с
       жёстким отсевом по удостоверению/медсправке/судимости, Тест 2
       «Психологическая пригодность» 6 вопросов) вместо одного, по
       финальному решению в test-questions-draft.md (2026-09-25)
2. [x] scenario.js — приветствие → анкета (пропуск если данные пришли с
       сайта) → Тест 1 (отсев на любом «нет»/«есть судимость» — сразу
       finish с причиной) → Тест 2 (только если Тест 1 пройден и набран
       проходной балл) → запись в Excel → рассылка на почту
3. [x] results-store.js — колонки под два теста + итоговый результат/
       причина отсева, data/candidates.xlsx копится построчно
4. [x] notify-email.js — рассылка после каждого теста (если задан EMAIL_TO)
5. [x] bot.js — /start /test /cancel, разбор start-параметра с сайта
6. [x] Запущен как systemd user-сервис `rzd-ohrana-bot.service`
       (enabled, автозапуск, Restart=always). Токен и
       NODE_EXTRA_CA_CERTS — в
       `~/.config/systemd/user/rzd-ohrana-bot.service.d/token.conf`
       (прямая запись `.env`-файла в проекте заблокирована на уровне
       прав доступа — писать секреты в systemd Environment=, как у
       bacey-bot/bacey-coordinator)
7. [x] Починен краш при каждом запросе к API: platform-api2.max.ru
       подписан российским Minцифры CA («Russian Trusted Sub CA»),
       которого нет в доверенных корнях Node.js по умолчанию — привело
       к бесконечному краш-циклу (`UNABLE_TO_GET_ISSUER_CERT_LOCALLY`).
       Добавлен bot/certs/ с официальными сертификатами (gu-st.ru),
       подключены через NODE_EXTRA_CA_CERTS.
